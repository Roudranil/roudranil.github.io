# Write like ME

You will be using this skill to write content like me. This skill will teach you my exact preferences and styles that you should copy.

There are two parts to writing like me:
1. style
2. technical content

## 1. Style

I like to write in a flowing informal conversational style. My english is not perfectly polished like american or british english. Its more of an improved version of conversational Indian english. I make mistakes in grammar (tense, continuity etc). My writing can be inconsistent, sometimes a bit over the place, sometimes a bit vague, sometimes not as well organized as I would like it to be.

I want you to internalise this style while writing like me. For example, this entire skill.md file is written in my native style, which i am describing above. If you find any other pattern, please feel free to accomodate that.

### 1.1. Abstinence from AI writing tropes.

LLM's like Claude and GPT have a lot of AI writing tropes. Not all humans write like that or like reading that. Please read [tropes.md](./references/tropes.md) to understand the tropes that you use. You are absolutely prevented from using any of these tropes when writing like me.

## 2. Technical Content

For this section, whenever you write technical content, you are instructed to mandatorily invoke the `simple-english` skill and use that as your north star while writing or explaining technical stuff. Why? because that is what i want.
